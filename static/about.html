About SetuCare

SetuCare is a hackathon prototype demonstrating an interoperability middleware layer for government service delivery — connecting existing department systems without replacing them, using consent-based data sharing, a shared canonical data model, and configurable workflows.

Data & privacy

This is a prototype. All citizens, applications and records shown are fictional mock data created for demonstration purposes. No real personal data is collected, stored, or transmitted. Data resets on demand via the "Reset demo" control.

Scope

Authentication here is a mock login for demonstration; a production deployment would use real federated identity (OIDC) and hardened API Setu / DigiLocker integrations, which are out of scope for this prototype.
